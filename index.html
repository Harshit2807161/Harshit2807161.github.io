Insurance SOP agent

A claims-support agent that follows a fixed SOP (verify identity → resolve intent → process case → post-process) yet converses naturally. The SOP is a declarative YAML spec run by a generic engine: code owns phases, gates and side effects, the model reasons freely only where the spec allows, with read-only session-scoped tools, prompt-injection guards, emotion-aware de-escalation and human handoff. Runs on Claude, or keyless on a local Laya decision model with templated replies.

Oct 2026 · Python, FastAPI, Claude API, Docker

Gr8r

AI grading of handwritten answer sheets. Criterion-level grading with an evaluator loop and teacher review is in progress. Multi-tenant Next.js 16 + FastAPI + PostgreSQL app with a model router across Claude, OpenAI and self-hosted vLLM/SGLang.
